تشغيل النظام (يتطلب Node.js 18 أو أحدث)
1) npm install
2) npm start
3) افتح http://localhost:3000

متغيرات اختيارية:
PORT=3000            منفذ التشغيل
DB_FILE=faces.db     مسار ملف قاعدة البيانات
BASIC_USER / BASIC_PASS   اسم مستخدم وكلمة مرور لحماية الصفحة والبيانات (مهم عند النشر)

ملاحظات:
- الكاميرا تعمل فقط عبر https أو localhost، فضع الخادم خلف Nginx أو Caddy مع شهادة SSL.
- البيانات في ملف faces.db، انسخه دوريًا كنسخة احتياطية.
- يمكنك أيضًا فتح public/index.html مباشرة، وسيعمل بوضع محلي بدون قاعدة بيانات.
